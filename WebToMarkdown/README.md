# WebToMarkdown

把网页**正文**或**选区**转成干净 Markdown，一键复制或下载 `.md`。界面 **中 / 英 / 日**。

## 功能（v0.2.4）

- **正文提取**：优先 `article` / `main`，否则按段落密度打分选主内容
- **仅选区**：先在页面划选，再转换选中 HTML
- **右键菜单**：选区 / 整页 → 转为 Markdown 并复制
- **选项**：附带标题与来源、**YAML front matter**、保留/去掉图片
- **去重标题**：正文已有 H1 时不再叠一层文档标题
- **预览页三种状态**：**MD** / **预览** / **分栏**（左右同步滚动、可拖分隔条）
- **本地历史**：载入 / 复制 / 单条删除 / 清空（本机，最多 30 条）
- **快捷键**：`Alt+Shift+M` 直接复制当前页 Markdown（角标 OK）

## 本地加载

1. `chrome://extensions` → 开发者模式  
2. 加载已解压扩展 → 选 `WebToMarkdown`  
3. 改代码后点 **重新加载**

## 权限说明

| 权限 | 用途 |
|------|------|
| `activeTab` / `scripting` | 读取当前页 DOM 并转换 |
| `storage` | 记住选项与本地历史 |
| `downloads` | 保存 `.md` 文件 |
| `contextMenus` | 右键「转为 Markdown 并复制」 |

数据默认在本地；不上传服务器。

## 限制

- 无法在 `chrome://`、扩展商店等受限页注入
- 强动态站点（大量广告壳、无语义结构）建议先**划选**或用右键选区
- 复杂表格 / 嵌套布局会简化为常见 Markdown
