# 插件路线图：值得做 / 有需求 / 市场相对空

> 目标：**自己每天能用** + **别人愿意付钱**。  
> 原则：避开「搜一下满屏免费替代」的通用小工具；做**窄场景、强工作流、可 freemium**。

---

## 一、明确不做（已验证饱和）

| 候选 | 原因 | 说明 |
|------|------|------|
| 颜色提取 / 吸管（ColorPicker） | 市场极卷 | ColorZilla、Pigment、Shademix 等已覆盖页面色板 + Eyedropper |
| 通用 AI 侧栏 / 摘要 / 改写 | 同质化 + 大厂占位 | Monica、Sider、Chrome 内置能力挤压生存空间 |
| 纯去广告 / 简单翻译 / 普通取色器 | 免费替代过多 | 难收费、难获客 |

`ColorPicker/` 文件夹保留为空壳或后续删除，**不纳入开发排期**。

---

## 二、推荐做（按优先级）

筛选标准：

1. **自用频率高** — 自己会反复打开  
2. **付费意愿清楚** — 有人/团队愿为省时间付钱  
3. **差异化空间** — 不是再做一个「差不多的 Tab 管理器」  
4. **可单人起步** — MV3 可先做本地版，再加云/团队  

### P0 — 先做：`PageAnnotate`（网页批注 / 反馈截图） ✅ MVP 已落地

| 项 | 内容 |
|----|------|
| 文件夹 | `PageAnnotate/`（v0.4.2：去掉卡片；复制≠下载；整页滚动长截图加强） |
| 状态 | **v0.4.2 可用**；云端分享链接仍待做 |
| 一句话 | 任意页面上框选、箭头、文字批注，一键截图或生成可分享的反馈卡片 |
| 自用场景 | 提 bug、对需求、给客户改设计、异步评审 |
| 市场需求 | 设计/产品/外包/客服高频；异步沟通替代「截图 + 微信来回」 |
| 市场缺口 | 国外 MarkUp / Pastel / Marker.io 偏重、偏贵、偏英文；**轻量中文 + 接收方免安装看图**仍是空位 |
| 关键差异化 | **分享链接对方不用装插件**（否则异步反馈链路断掉） |
| MVP | 页面涂鸦层 + 截图复制/下载 + 本地历史；先不做云 |
| Pro 卖点 | 云端分享链接、团队空间、历史、去水印、品牌定制 |
| 收费假设 | 免费基础截图；Pro 约 $5–7/月 或国内等价年费 |

**为何排第一**：最好演示（30 秒出效果）、获客路径短、自用即验证产品。

---

### P1 — 第二做：`WorkSession`（按项目的标签 / 会话工作区）

| 项 | 内容 |
|----|------|
| 文件夹 | `WorkSession/` |
| 一句话 | 按「项目 / 客户」一键保存、休眠、恢复整组标签（含分组名） |
| 自用场景 | 多项目并行、早上开工一键恢复、下班一键收起 |
| 市场需求 | 远程办公、咨询、运营、研究类用户；会话类工具有持续付费验证 |
| 市场缺口 | Workona / Toby 等偏英文、偏重；**超轻量 + 中文 + 不崩 + 可选同步**仍有空间 |
| 关键差异化 | 极低内存、按项目命名、休眠省资源、后期跨设备同步 |
| MVP | 本地保存/恢复会话、命名工作区、快捷键；先不上云 |
| Pro 卖点 | 无限工作区、云同步、导入导出、团队共享模板 |
| 收费假设 | 免费 2–3 个工作区；Pro 订阅 |

**注意**：不要做成「又一个 OneTab」；卖点是**项目上下文切换**，不是单纯关标签省内存。

---

### P2 — 有明确 B 端再做：`EnvSwitch`（多账号 / 多环境切换）

| 项 | 内容 |
|----|------|
| 文件夹 | `EnvSwitch/` |
| 一句话 | 同一站点在测试 / 预发 / 正式，或客户 A / B 账号间一键切换（隔离会话） |
| 自用场景 | 多环境联调、代管多客户后台 |
| 市场需求 | 外包、代运营、QA、代理商 — 客单价通常高于个人工具 |
| 市场缺口 | 通用多账号工具有，但**面向「环境 + 客户站点配置」的中文轻量方案**不多 |
| 关键差异化 | 按「环境配置档」管理（URL 规则 + cookie 档），安全说明清晰、数据默认本地 |
| MVP | 按域名保存多套 cookie 会话并切换；明确权限与风险文案 |
| Pro 卖点 | 团队配置下发、审计日志、更多席位 |
| 风险 | 涉及会话数据，信任与合规是付费门槛；需谨慎设计存储与文案 |

**建议**：个人验证 P0/P1 有人用之后，再开 P2；或你日常强依赖多客户后台时提前做。

## 三、备选池（有需求，但优先级靠后）

| 文件夹（暂定） | 方向 | 为何靠后 |
|----------------|------|----------|
| `PageMeasure` | 页面元素量尺 / 间距对齐 | 自用强，付费弱，可作 PageAnnotate 附属能力 |
| `FormFixture` | 测试表单假数据填充 | 开发/QA 刚需，市场规模偏小 |
| `ClipVault` | 本机剪贴板历史（隐私优先） | 系统级竞品多，差异化难 |
| `ChangeWatch` | 指定页面变更监控提醒 | 有需求，但后台/通知成本高，适合后期 |

## 五、产品原则（整仓统一）

1. **先本地、后云端** — MVP 不依赖账号体系，降低上架与开发成本  
2. **免费能完成主路径** — 付费买的是同步、团队、分享、额度，不是「能用」  
3. **一个插件只做一件主事** — 集合仓库靠文件夹拆分，不做成巨型套件  
4. **中文体验优先** — 文案、默认工作流按国内协作习惯（微信/飞书转发截图、免安装查看）  
5. **权限最小化** — README 写清为何要某权限；涉及 cookie/会话的插件单独强调安全
