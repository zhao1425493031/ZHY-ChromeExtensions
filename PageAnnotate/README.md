# PageAnnotate

网页批注与截图工具。支持问题说明、区域截图、**整页滚动长截图**、贴图、高亮、马赛克、编号、延时。界面 **中 / 英 / 日**。

## 功能（v0.4.4）

- **批注**：画笔、矩形、高亮、箭头、直线、文字、编号、马赛克、区域、插图、选择
- **复制**：只复制当前画面到剪贴板  
- **下载 / 保存**：只下载当前画面文件  
- **整页滚动**：自动滚动拼接长图（完成后下载+复制，并新标签打开原尺寸图；不再缩略贴回画布）
- **延时**：0 / 2 / 3 秒，适合截悬浮菜单
- **线宽 / 撤销重做 / 本地历史 / i18n**

## 本地加载

1. `chrome://extensions` → 开发者模式  
2. 加载已解压扩展 → 选 `PageAnnotate`  
3. 改代码后点 **重新加载**

## 快捷键

| 键 | 作用 |
|----|------|
| `Alt+Shift+A` | 开关批注 |
| `Esc` | 退出 |
| `1`–`9` / `0` | 切换工具 |
| `I` | 插图 |
| `Delete` | 删除选中 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+V` | 粘贴图片 |

> 整页滚动会暂时隐藏批注层；页面不足两屏时会提示并只截当前画面。
