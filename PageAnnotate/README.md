# PageAnnotate

网页批注与截图工具。支持问题说明、区域/长截图、贴图、高亮、马赛克、编号、延时截图、导出卡片。界面 **中 / 英 / 日**。

## 功能（v0.4）

- **批注**：笔、框、高亮、箭头、直线、文字、编号、马赛克、区域截图、贴图、选择
- **编号**：点「号」依次放置 1、2、3…（可「选」拖动，`Delete` 删除）
- **延时**：点「延」在 0 / 2 / 3 秒间切换，适合截悬浮菜单
- **长截图**：点「长」滚动拼接整页（上限约 12000px），复制并下载
- **卡片**：导出含标题、URL、说明的图片
- **线宽 / 撤销重做 / 本地历史 / i18n**

## 本地加载

1. `chrome://extensions` → 开发者模式  
2. 加载已解压扩展 → 选 `PageAnnotate`  
3. 改代码后点 **重新加载**

## 快捷键

| 键 | 作用 |
|----|------|
| `Alt+Shift+A` | 开关批注 |
| `Esc` | 退出 |
| `1`–`9` / `0` | 笔框亮箭线字号码区 / 选 |
| `I` | 插图 |
| `Delete` | 删除选中 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+V` | 粘贴图片 |

> 长截图会暂时隐藏批注层以抓取页面本身；超长页面会截断以防内存过大。
